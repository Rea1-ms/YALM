# YALM（机械革命助手）

面向机械革命笔记本的轻量控制工具，把性能模式、风扇、键盘背光和常用设置放在一个窗口里。基于 [G-Helper（华硕控制工具）](https://github.com/seerge/g-helper) 改造，提供单文件便携版，无需安装。

**[下载单文件版](https://github.com/Rea1-ms/YALM/releases/latest/download/YALM.exe) · [压缩包与发布说明](https://github.com/Rea1-ms/YALM/releases/latest) · [反馈问题](https://github.com/Rea1-ms/YALM/issues) · [常见问题](#常见问题)**

> [!IMPORTANT]
> 目前仍需保留适配的机械革命控制中心后台服务及驱动。使用助手时，请退出官方控制中心的窗口和托盘，避免多个控制界面同时修改设置。各项功能的可用范围取决于机型和固件。

## 主要功能

- **性能模式**：切换安静、均衡、狂暴模式，以及支持机型的自定义配置。
- **风扇与功耗**：编辑自定义风扇曲线、调整已适配的功耗参数，切换风扇增强。
- **状态监控**：查看温度、风扇实际转速和控制百分比，支持屏幕叠加显示。点击主窗口的温度与风扇读数，可切换百分比和实际转速。
- **键盘与背光**：调整灯效、颜色和亮度，切换功能键锁定与系统键锁定。
- **显卡模式**：切换混合模式与独显直连，需要重启的设置会显示提示。
- **常用设置**：功能键提示、数字键盘锁定、触摸板切换键、关机供电、来电自动开机和窗口置顶。
- **托盘与自启**：关闭窗口后保留托盘；右键可访问常用功能，支持登录后隐藏启动。
- **程序更新**：自动检查正式发布版，确认后下载并重启，也可从托盘手动检查。

## 下载与使用

1. 下载 [YALM.exe（单文件程序）](https://github.com/Rea1-ms/YALM/releases/latest/download/YALM.exe)，保存到一个固定目录，无需解压。也可以从[发布页面](https://github.com/Rea1-ms/YALM/releases/latest)下载压缩包，解压后同样只有这一个程序。
2. 使用 64 位 Windows（操作系统），并安装 [.NET 10 Desktop Runtime（桌面运行时）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0) 的 x64（64 位）版本。
3. 退出官方控制中心及其托盘，保留后台服务和驱动，然后运行 `YALM.exe`（助手程序）。程序会自动尝试连接本机服务，无需手动填写连接资料或以管理员身份运行。

“更多设置”中的“开机自启动”默认关闭。开启后，登录时会隐藏到托盘，不会自动切换性能模式。关闭主窗口仍会继续运行，完全退出请使用窗口或托盘菜单中的“退出”。

只想先看看界面，可以加上 `--demo`（演示）参数启动；演示模式不连接设备，也不修改硬件设置。

## 适配范围

当前主要适配旷世 16 Pro（专业版），主板型号为 GM6PX0X（型号标识）。其他机型根据厂商服务和固件能力提供部分功能，尚未覆盖全部机械革命设备。

| 设备或识别结果 | 当前可用范围 |
| --- | --- |
| 已验证的旷世 16 Pro（专业版）主板 | 性能模式、自定义曲线、部分功耗、键盘背光、显卡模式及快捷设置 |
| 其他已适配的服务与固件 | 部分支持预设性能模式；另一些仅提供模式、温度或转速读取 |
| 尚未识别的硬件协议 | 连接成功后尝试显示服务回报，未开放硬件控制 |

蛟龙、翼龙、部分旧商用机型和迷你主机已接入部分只读接口，不能据此认为同系列所有型号都能使用全部功能。未完成实机验证的可控机型默认只读，可在“更多设置”中查看“允许写入”的状态和提示；勾选不会解锁尚未实现的协议。

具体范围见[机型与协议适配说明](docs/按协议能力扩展机型适配记录.md)和[其他机型的只读适配说明](docs/剩余机型协议只读适配记录.md)。

## 常见问题

<details>
<summary>可以卸载官方控制中心吗？</summary>

目前建议保留。助手仍依赖厂商后台服务与驱动，使用时只需退出官方控制中心的窗口和托盘。助手不会代你安装、卸载或停止这些组件。

</details>

<details>
<summary>为什么部分按钮不可用，或者一直显示“未收到”？</summary>

先查看主窗口底部的状态提示。机型尚未适配、官方控制中心仍在运行、未允许写入，或供电和设备状态不满足条件时，相关操作会暂停。狂暴模式还需要机型支持并接通电源。

“未收到”表示没有取得可用读数，不等于温度或转速为零。风扇百分比是控制值，实际转速单独读取，两者不能直接换算。

仍有问题时，可在“更多设置”打开日志或导出诊断信息，再到[问题页面](https://github.com/Rea1-ms/YALM/issues)反馈。请附上机型、官方控制中心版本和复现步骤，不要上传连接凭据。

</details>

<details>
<summary>会自动安装更新吗？</summary>

不会。程序每 12 小时检查一次正式发布版，有新版时提示；确认后才下载、校验、替换并重启。点击主窗口底部的版本信息或托盘中的“检查程序更新”也可手动检查，“更多设置”可以关闭自动检查。

自更新适用于单文件便携版，保留用户设置和旧程序备份；替换或启动请求失败时尝试恢复旧程序。确认新版运行正常后，可自行清理备份及更新缓存。更多说明见[自更新说明](docs/自更新实现记录.md)。

</details>

<details>
<summary>设置保存在哪里？</summary>

用户设置保存在 `%APPDATA%\YALM`（用户应用数据目录），替换程序不会清除设置。更新缓存保存在 `%LOCALAPPDATA%\YALM\Updates`（用户本地更新目录），旧程序备份保存在原程序旁。

</details>

## 开发

需要 .NET SDK（开发工具包）10.0.402，以及 PowerShell 7（命令行工具）。在项目根目录执行以下命令，依次完成构建、离线回归、离线界面检查和便携版打包：

```powershell
dotnet build YALM.slnx -c Release
dotnet run --project tests/YALM.Tests/YALM.Tests.csproj
dotnet run --project tests/YALM.UiTests/YALM.UiTests.csproj -c Release
.\Publish.ps1
```

打包脚本通过离线演示自检后，在 `artifacts/portable`（便携版输出目录）同时生成 `YALM.exe`（单文件程序）和 `YALM-win-x64.zip`（分发压缩包）；压缩包内仅包含同一个单文件程序。使用 Rider（开发工具）时，也可以选择“一键打包”运行配置。

协议分析和历史验证资料保存在 `docs`（文档目录）。
